## Suggested captions

1. **Learn one verified step at a time.** A local-first workspace pairs a live Codex tutor with durable progress.
2. **Clear ownership at every boundary.** Learning records stay local, Codex owns authentication, and GPT-5.6 powers tutoring.
3. **One focused learning surface.** Conversation, objectives, notes, bookmarks, and progress stay tied to the project.
4. **Learning state survives restart.** Confirmed history and project context return from local SQLite storage.
5. **Progress requires evidence.** Unsupported self-report is excluded from core attainment.
6. **Objectives remain inspectable.** The learner can see what is active, saved, and still incomplete.

desktop content, and private project names. Only the files listed above are approved candidates.
