# 教育課程・カリキュラム資料

当初調査した8教育管轄プロファイルについて、2026年7月18日時点の原資料、取得失敗記録、機械可読な構造化概要を保存しています。MVP対象は公式原資料を取得できた日本1、米国3、ドイツ3の7教育管轄プロファイルです。

## ディレクトリ

- `raw/`: 公式サイトから取得したPDFまたはHTML、取得失敗を示す0バイトファイル、MVP対象外資料の調査用スナップショットです。再配布条件を確認できていない原資料はローカル専用であり、Git対象外です。著作物を含まない0バイトの失敗プレースホルダーだけを追跡します。
- `structured/`: 管轄ごとのYAMLです。発行主体、版、対象段階、原資料、SHA-256、用語辞書、上位の教育課程項目を保持します。
- `../tests/test_curricula_data.py`: 8件数、必須項目、取得済みローカル原資料のSHA-256、失敗プレースホルダー、用語辞書を検証します。

## 対象範囲

要件定義書では各管轄の教育段階、学年、教科、版が未決定です。比較可能性を確保するため、日本・米国3管轄・ドイツ3州は数学の公式資料を選定しました。構造化YAMLは原資料の上位階層と用語体系を表す概要であり、全到達事項の逐語転記ではありません。詳細記述の正本は`raw/`の原資料です。

UAEについては、MoE公式配信元がHTTP 502を返したため、同省の表紙と著作権表示を持つ`Bridge to Success Grade 11 Teacher's Guide`を第三者ミラーから取得しました。公式配信元の失敗ファイルは0バイトのプレースホルダーとして保存しています。公式取得経路と再配布条件を検証できないためUAEはMVP対象外であり、アプリの選択肢、初期データ、受入試験、配布物へ含めません。`structured/08_uae.yaml`は削除せず、将来の再評価に使用する調査記録として保持します。

## Terminology方針

管轄間で用語を無理に統一していません。同一YAML内では、各発行主体の原語を正規用語として固定しています。各ファイルの`terminology.canonical_terms`は、アプリ共通概念へ対応付けるための辞書です。

例:

- 日本: `内容領域`
- DC・NY: `Domain`
- California: `Content Connection` / `Big Idea`
- Berlin・Hamburg: `Leitidee`
- Bayern: `Lernbereich`
- UAE: `Unit` / `Learning objective` / `Learning outcome`

## 更新手順

1. 公式発行主体のページから原資料を再取得します。
2. URL、版、取得日、SHA-256を該当YAMLへ反映します。
3. 同一ファイル内の用語を`terminology.canonical_terms`へ合わせます。
4. `python -m unittest tests/test_curricula_data.py`を実行します。

取得に失敗したURLは削除せず、0バイトのプレースホルダーファイルと`failed_*`の`retrieval_status`を保存します。これにより、未取得と未調査を区別できます。
