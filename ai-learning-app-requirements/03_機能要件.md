# 03 機能要件

[INDEXへ戻る](00_INDEX.md)

優先度は Must（MVP必須）、Should（早期対応）、Could（将来対応）です。

## 1. 認証・ローカルプロフィール

| ID | 要件 | 優先度 |
|---|---|---|
| FR-A01 | ChatGPTアカウントを使用してログインを開始できます。 | Must |
| FR-A02 | ChatGPT認証状態を表示し、ログアウトできます。 | Must |
| FR-A03 | ローカルプロフィールの表示名、言語、タイムゾーンを設定できます。 | Must |
| FR-A04 | ChatGPT認証情報の削除と端末内学習データの削除を個別に実行できます。 | Must |
| FR-A05 | 説明の好みを設定できます。 | Should |
| FR-A06 | OSの資格情報ストアに保存した認証状態をアプリ再起動後に再利用できます。 | Must |
| FR-A07 | ChatGPTアクセストークンをアプリDB、画面、診断ログに保存・表示しません。 | Must |
| FR-A08 | 認証情報を永続保存する場合はOS資格情報ストアを必須とし、利用不能時はファイル、SQLite、設定、バックアップへフォールバック保存しません。 | Must |
| FR-A09 | 認証URL、ログイン試行、完了イベントを検証し、未要求、重複、期限切れ、試行ID不一致の認証完了を拒否します。 | Must |

MVPではOSユーザー単位の単一ローカルプロフィールを扱います。ChatGPT認証はCodex利用権限の確認に使用し、学習データの所有境界はOSユーザープロフィールとします。説明の好みには、簡潔／詳細、理論／具体例、対話／講義、数式量、専門用語レベルを含みます。

## 3. 教育課程・根拠資料

| ID | 要件 | 優先度 |
|---|---|---|
| FR-G01 | MVPで対応する8教育管轄プロファイルと、その配下の教育課程を国・地域、管轄種別、発行主体、教育段階、学年、教科、版とともに登録できます。 | Must |
| FR-G02 | 教育課程の項目、到達目標、前提関係を構造化して保存します。 | Must |
| FR-G03 | 教育内容の根拠となるWeb資料を検索または取得できます。 | Must |
| FR-G04 | 根拠資料のURL、題名、発行主体、公開日または版、取得日時、言語、ライセンス情報を保存します。 | Must |
| FR-G05 | 学習計画、レッスン、説明、演習、採点根拠から使用した資料を追跡できます。 | Must |
| FR-G06 | ユーザーが説明に対応する出典と教育課程項目を確認できます。 | Must |
| FR-G07 | 公的資料、教育機関資料、補助資料を区別し、信頼度と用途を表示します。 | Must |
| FR-G08 | 根拠資料を取得できない、資料間で矛盾する、対象版を特定できない場合に断定を避け、状態を表示します。 | Must |
| FR-G09 | 許可された読取り専用経路以外からWeb資料を取得しません。 | Must |
| FR-G10 | 取得済み資料の内容ハッシュまたはスナップショットにより、後日の変更を検出できます。 | Should |
| FR-G11 | 国単位、州、ドイツの州（Land）、米国の連邦直轄地区を区別し、州相当区域を州と誤表示しません。 | Must |
| FR-G12 | 各教育管轄プロファイルの選定根拠となる都市、選定区分、人口順位・人口値・基準日・出典、公式教育当局を追跡できます。 | Must |
| FR-G13 | 教育課程原文の到達目標を保持し、学習計画で使用する際は`can_do`または`know`の学習目標へ変換して原文との対応を保存します。 | Must |
| FR-G14 | 教育課程学習では、計画、目標、前提関係、概念、評価に関連付ける全教育課程項目が、学習テーマと同じ教育管轄プロファイルに属することを検証します。 | Must |

MVPの教育管轄プロファイルは、日本、コロンビア特別区、ニューヨーク州、カリフォルニア州、ベルリン州、ハンブルク州、バイエルン州、UAEの8種類に固定します。日本は文部科学省の学習指導要領、UAEはUAE教育省の教育課程を基準にします。米国はOSSE、NYSED、CDEが公表する学習標準・フレームワーク、ドイツは各州が公表するRahmenlehrpläne、BildungspläneまたはLehrpläneを基準にします。

「8種類」は教育管轄別の基準セット数です。教育段階、学年、教科、版ごとの`Curriculum`レコード数を8件に制限するものではありません。各プロファイルで提供する詳細範囲は限定し、データ構造は追加の国・地域・州、教育段階、学年、教科、版を拡張可能にします。

## 4. 初期診断

| ID | 要件 | 優先度 |
|---|---|---|
| FR-D01 | AIがテーマ別診断問題を生成します。 | Must |
| FR-D02 | 診断をスキップできます。 | Must |
| FR-D03 | 選択式・自由記述式を出題できます。 | Must |
| FR-D04 | 回答から既知・未習得概念を推定します。 | Must |
| FR-D05 | 診断結果を修正できます。 | Should |
| FR-D06 | 結果を学習計画へ反映します。 | Must |
| FR-D07 | 未習得概念だけでなく不足している前提概念を特定します。 | Must |
| FR-D08 | 診断問題と判定根拠を教育課程項目および根拠資料へ関連付けます。 | Must |

結果は単一スコアではなく概念ごとの理解状態として保存します。「診断」は、ユーザが学ぼうとする領域・テーマについて、どの程度習熟しているかを測定し、その後のPersonalizeに活かす目的で行います。

## 5. 学習計画

| ID | 要件 | 優先度 |
|---|---|---|
| FR-L01 | 目標・診断結果から計画を生成します。 | Must |
| FR-L02 | モジュール(セクション)、レッスン、概念に分割します。 | Must |
| FR-L03 | 各レッスンに1つ以上の学習目標と想定時間を設定します。 | Must |
| FR-L04 | 前提関係を考慮して順序付けします。 | Must |
| FR-L05 | 順序、名称、重点項目を編集できます。 | Must |
| FR-L06 | 進捗・誤答傾向から再生成できます。 | Must |
| FR-L07 | 旧計画を保持し差分確認できます。 | Should |
| FR-L08 | 計画外内容を追加レッスンとして保存できます。 | Should |
| FR-L09 | 教育課程学習では、計画項目と教育課程項目の対応を保存・表示します。 | Must |
| FR-L10 | 前提理解が不足した場合、前段階の補習レッスンを挿入し、元の学習位置への復帰条件を保持します。 | Must |
| FR-L11 | 各レッスンに主要な根拠資料を関連付けます。 | Must |
| FR-L12 | 最終目標、モジュール目標、レッスン目標を`can_do`（できる）または`know`（わかる）のいずれか一方に分類して表示します。 | Must |
| FR-L13 | 各学習目標に目標文、対象、達成条件、成功基準、評価証拠の取得方法を設定します。 | Must |
| FR-L14 | 1つのモジュールまたはレッスンに`can_do`と`know`を混在できますが、個々の学習目標は両方へ重複分類しません。 | Must |

計画は自由文だけでなく構造化データとして取得・保存します。`can_do`は指定条件のもとで実行する観測可能な行動と成功基準を含めます。`know`は知識・理解の対象に加え、説明、区別、関連付け、理由提示などの観測可能な評価方法を含めます。「理解する」「知る」だけの目標文や、ユーザーの自己申告だけでは`know`の達成とみなしません。

## 7. 演習・評価

| ID | 要件 | 優先度 |
|---|---|---|
| FR-Q01 | 現在内容に対応する問題を生成します。 | Must |
| FR-Q02 | 選択式、自由記述式、穴埋め式に対応します。 | Must |
| FR-Q03 | 採点し、理由と改善点を返します。 | Must |
| FR-Q04 | 不正解時は正解の前にヒントを選べます。 | Must |
| FR-Q05 | 自己評価を入力できます。 | Must |
| FR-Q06 | 難易度を自動調整します。 | Should |
| FR-Q07 | 過去の誤答から復習問題を生成します。 | Should |
| FR-Q08 | 総合確認テストを実施できます。 | Must |
| FR-Q09 | 採点不能・曖昧な回答を断定的に誤答としません。 | Must |
| FR-Q10 | 問題、模範解答、採点基準を教育課程項目と根拠資料へ関連付けます。 | Must |
| FR-Q11 | 前提概念の誤りと現在レッスン固有の誤りを区別します。 | Must |
| FR-Q12 | 診断、演習、確認テストを対象の学習目標へ関連付け、`can_do`または`know`の達成証拠として追跡します。 | Must |

自由記述評価では、点数、根拠、満たした観点、不足観点を保存します。

## 8. 進捗・習熟度

| ID | 要件 | 優先度 |
|---|---|---|
| FR-M01 | テーマ全体の進捗率を表示します。 | Must |
| FR-M02 | モジュール、レッスン、概念単位で状態表示します。 | Must |
| FR-M03 | 概念別習熟度を保存します。 | Must |
| FR-M04 | 根拠となる回答・テストを追跡できます。 | Must |
| FR-M05 | 苦手概念を一覧表示します。 | Must |
| FR-M06 | 次の内容と復習候補を提示します。 | Must |
| FR-M07 | 学習時間、回数、連続日数を表示します。 | Should |
| FR-M08 | 教育課程項目ごとの到達状況を表示します。 | Must |
| FR-M09 | 前段階へ戻っている状態、復帰条件、元の学習位置を表示します。 | Must |
| FR-M10 | 学習目標ごとの種類、状態、成功基準、達成判定に使用した証拠を表示します。 | Must |
| FR-M11 | 学習目標の達成状態はApplication Coreが検証済み証拠から算出し、RendererまたはLLMが達成済み状態を直接設定できません。 | Must |
| FR-M12 | 学習目標、成功基準、証拠、ルーブリック、採点結果が変更・削除・再評価された場合、影響する達成判定を失効または再計算します。 | Must |

状態は未学習、学習中、要復習、習得、保留です。習熟度は診断、正答、一貫性、ヒント、復習成績、自己評価から算出し、LLMの主観点をそのまま保存しません。
