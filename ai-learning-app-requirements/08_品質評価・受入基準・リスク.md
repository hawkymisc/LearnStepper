# 08 品質評価・受入基準・リスク

[INDEXへ戻る](00_INDEX.md)

## 1. オフライン評価

8教育管轄プロファイルについては、各プロファイルでMVP対象に固定した教育段階・学年・教科・版だけを対象とする教育課程準拠評価セットを用意します。これとは別に、管轄非依存の初等数学、統計、プログラミング、語学、歴史、自然科学、資格学習、高リスク領域の一般品質・安全性評価セットを用意します。正確性、分かりやすさ、レベル適合、教育課程との対応、前提関係、補習経路、計画妥当性、学習目標の`can_do`／`know`分類、目標と評価証拠の整合、問題・解答整合、採点一貫性、出典充足率、引用整合性、資料間矛盾処理、不確実性、安全性、構造化出力成功率を評価します。

教育課程準拠の評価では、対象国・地域、教育管轄プロファイル、発行主体、教育段階、学年、教科、版を固定した期待データを使用します。8プロファイルを相互に独立した評価区分とし、同一国の別州の期待データを流用しません。LLM出力だけを正解データとして使用しません。

## 2. プロダクト内評価

役に立った／立たない、難しすぎる／適切／簡単すぎる、誤り、出典が不適切、教育課程と不一致、質問に未回答、長すぎる、自由記述を端末内に保存できます。

品質改善のため外部送信する場合は、送信対象を表示して明示同意を得ます。低評価データを送信する場合も、会話本文、根拠資料、個人情報を自動的に含めません。

## 3. 成功指標

プロダクト指標は、ChatGPTログイン成功、教育課程またはテーマ作成、根拠資料取得、計画承認、初回開始・完了、7日再訪、テーマ完了、演習実施、補習経路完了、計画再生成、回答肯定評価の各率です。

学習成果指標は、診断と最終テストの得点差、教育課程項目の到達率、`can_do`目標達成率、`know`目標達成率、習得概念の復習正答率、ヒント回数減少、同一概念誤答率低下、補習後の元レッスン復帰率、自己設定目標達成率です。滞在時間だけを成果にしません。

これらの指標は端末内で算出可能にします。運営側への送信をMVPの成立条件にしません。

## 4. MVP受入基準

### AC-00 standalone起動・ChatGPT認証
配布されたデスクトップアプリだけでApplication Core、SQLite、Codex App Serverを起動できます。未認証時は検証済みの公式HTTPS認証URLでChatGPTログインを開始でき、ログイン試行と完了イベントの照合および認証状態の再確認後に利用可能状態へ移行します。アプリ再起動後はOS資格情報ストアに保存済みの認証を再利用でき、ログアウト後は再認証が必要です。資格情報ストアが利用不能な場合は平文フォールバック保存を行いません。

### AC-01 学習テーマ作成
教育課程学習では対応済みの国・地域、教育段階、学年、教科、版を選択でき、任意テーマ学習ではテーマを入力できます。目的、レベル、期間と、`can_do`または`know`で表した1つ以上の最終学習目標を保存し、モジュールとレッスンから成る計画を生成・表示できます。

### AC-02 対話型レッスン
質問送信、ストリーミング表示、生成停止、中断状態保存、その後の新規質問送信ができます。事実主張に対応する出典を表示し、出典を開いて確認できます。

### AC-03 アプリ再起動・セッション再開
アプリ終了後も同じテーマを開き、前回位置、要約、進捗、確定済み会話、対応教育課程項目を表示し、既存テーマへ新メッセージを関連付けできます。

### AC-04 演習
現在レッスンの問題生成、回答保存、採点・根拠・改善点表示、概念習熟度反映ができます。問題、模範解答、採点基準から学習目標、教育課程項目、根拠資料を追跡できます。

### AC-05 進捗・補習
テーマ、モジュール、レッスン、概念、教育課程項目の進捗と苦手概念、次回推奨を表示できます。前提理解が不足した場合、前段階へ戻る理由、補習内容、元の学習位置、復帰条件を表示できます。

### AC-06 障害・オフライン対応
App Server切断またはオフライン状態を区別して表示し、入力を失わず、重複ターンを作らず、保存済み計画、進捗、履歴、保存可能な根拠資料を閲覧できます。App Server再起動後に未完了ターンを整合できます。

### AC-07 データ削除
ChatGPTログアウトだけでは学習データを削除しません。テーマのアーカイブと削除は別操作とし、テーマ削除ではアプリDBの関連データと対応Codexスレッドを削除して通常一覧・履歴から消します。全ローカルデータ削除ではSQLite本体・WAL、保存済み根拠資料、スナップショット、アプリ専用Codex状態、Codex認証情報、キャッシュ、ログ、下書き、一時ファイルを対象として確認後に削除できます。部分失敗は完了扱いにせず、対象別結果と再試行経路を表示します。

### AC-08 Grounded Documents・教育課程準拠
教育内容から、使用した根拠資料のURL、題名、発行主体、版または公開日、取得時点を確認できます。教育課程学習ではレッスンと教育課程項目の対応に加え、変換後の学習目標から教育課程原文目標の公式コード、原文、出典位置、変換版を確認できます。同一`CurriculumItem`に原文目標を2件以上持つ試験データを使用し、各変換後目標が意図した原文目標だけへ対応することを契約試験で確認します。根拠資料が取得不能、版不明、相互矛盾の場合、検証済み教材として断定表示しません。

### AC-09 8教育管轄プロファイル
日本、コロンビア特別区、ニューヨーク州、カリフォルニア州、ベルリン州、ハンブルク州、バイエルン州、UAEの8種類が安定キー付きの選択肢として表示され、各プロファイルで固定した教育段階・学年・教科・版を選択できます。各プロファイルが別の公式教育当局と根拠資料へ対応し、米国・ドイツの別州の標準を混在させません。コロンビア特別区は州ではなく州相当教育管轄として表示します。例えばニューヨーク州のテーマへカリフォルニア州の項目または前提項目を関連付ける要求は`CURRICULUM_JURISDICTION_MISMATCH`となり、部分保存されません。

### AC-10 `can_do`／`know`学習目標
最終目標、モジュール目標、レッスン目標は、それぞれ「できる」または「わかる」として表示されます。個々の目標は`can_do`または`know`の一方だけを持ち、目標文、対象、条件、成功基準、評価証拠の取得方法を確認できます。`can_do`は観測可能な行動で評価し、`know`は説明、区別、関連付け、理由提示などで評価します。自己申告だけでは達成状態にならず、達成判定から使用した診断、演習、確認テスト、不変の目標版ID、ルーブリック版、評価日時を追跡できます。目標編集後も旧版の目標文、条件、成功基準、評価方法、教育課程原文対応を復元できます。達成状態はApplication Coreだけが算出します。

契約試験では、同一モジュール内の`can_do`と`know`の正常な混在、目標1件、スキーマで宣言した上限件数を受理します。目標0件、上限超過、`goal_type`の欠落・null・未知値・重複指定、`scope`と参照IDの不整合、必須文字列の空・空白のみ、観測不能な目標、別目標・別版・削除済み証拠は`VALIDATION_ERROR`として確定保存しません。自己評価は保存できますが`SELF_REPORT_ONLY`として達成証拠に採用せず、自己評価だけで達成済みに設定する要求を拒否します。旧版向けAssessmentの生成後に目標を改版して回答した場合、その証拠は旧版だけへ関連付け、新版への関連付けを`VALIDATION_ERROR`として拒否します。目標または評価条件の変更後は旧達成判定が失効または再計算されます。

### AC-11 Codex権限・Grounding境界
MVP起動時にApp Serverのツール許可集合が空、承認方針が既定拒否、OSサンドボックスが有効であることを確認します。未知のツール、設定欠落、ツール有効化を検出した場合は学習セッションを開始しません。承認要求はRendererへ転送されず拒否されます。Groundingは専用Gatewayだけを使用し、非HTTPS、非公開・特殊IP、DNS再束縛、非許可ポート、URL内資格情報、制限超過文書を拒否します。

## 5. 主要リスクと対策

| リスク | 対策 |
|---|---|
| 誤説明 | 不確実性表示、出典対応、評価セット、高リスク注意表示 |
| 出典は存在するが主張を支えていない | source IDと引用範囲の検証、引用整合性評価、未検証表示 |
| 教育課程の国・地域・版が不一致 | 発行主体・版の明示、構造化ID、対象範囲を限定した受入試験 |
| 同一国内の州別教育課程が混在 | 教育管轄プロファイルによる分離、管轄ごとの公式資料対応、8区分の回帰試験 |
| Web資料の変更・消失 | 取得時点と内容ハッシュ、ライセンスが許す場合のスナップショット、再検証 |
| 根拠資料中のプロンプトインジェクション | 取得内容を信頼しない境界、命令と教材本文の分離、ツール権限制限 |
| 採点不一致 | ルーブリック、根拠資料、構造化出力、評価セットによる回帰試験 |
| `know`目標が「理解する」だけで評価不能 | 観測可能な評価方法の必須化、自己申告だけでの達成禁止、目標と評価証拠の契約試験 |
| 長い会話で文脈崩壊 | 要約、アプリDBの概念状態、必要な教育課程項目・資料のみ再注入 |
| 過大な計画 | 期間、1回時間、教育課程の前提関係による制約 |
| ChatGPT認証または利用制限 | 認証状態・レート制限表示、入力保持、再ログイン、利用不能時のローカル閲覧 |
| 第三者デスクトップアプリでのChatGPT認証要件変更 | OpenAIへの公開利用条件確認、Codexバージョン固定、認証契約試験 |
| App Server更新で非互換 | バージョン固定、生成スキーマ、契約テスト、段階更新 |
| ローカル履歴消失 | SQLiteトランザクション、破損検出、バックアップ・エクスポート方針、削除確認 |
| 複数端末で状態を共有できない | MVP対象外として明示し、将来の同期方式で対応 |
| AIを専門家の代替に使用 | 高リスク識別、用途制限、専門家相談案内 |
| 未成年者の利用 | 対象年齢、保護者同意、データ取扱いを実装前に決定 |
| ツール副作用 | MVP無効化、将来も明示承認 |
