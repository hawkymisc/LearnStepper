# 02 ユーザーとユースケース

[INDEXへ戻る](00_INDEX.md)

## 1. 対象ユーザー

独学で新しい知識やスキルを身につけたい個人に加え、地理的制約や人間関係上の事情などにより既存の教育機会へ継続的に参加しにくい学習者を主対象とします。例として、教育課程に沿って学び直す人、数学・統計を復習する学生、資格学習中の社会人、プログラミング初学者、業務知識を習得する会社員、歴史・語学・科学を学ぶユーザーを含みます。

典型的な状態は、テーマは決まっているが順序が分からない、現在レベルを正確に把握していない、教材を読むだけでは継続しにくい、不明点をその場で質問したい、短時間でも進めたい、というものです。

## 2. 初回学習開始

1. デスクトップアプリを起動し、ChatGPTアカウントでログインします。
2. 教育課程に沿った学習または任意テーマ学習を選びます。
3. 教育課程学習ではMVPの7教育管轄プロファイルから1つを選び、教育段階、学年、教科、版を選びます。任意テーマ学習ではテーマを自由入力します。
4. 学習目的、現在レベル、目標レベル、希望期間を設定します。アプリは学習目的から最終学習目標を`can_do`（できる）または`know`（わかる）として構造化し、ユーザーが確認・編集します。
5. アプリが対象教育課程と根拠資料を提示し、ユーザーが確認します。
6. 必要に応じて初期診断を受けます。
7. AIが前提関係と診断結果を反映し、各レッスンの学習目標を`can_do`または`know`で示した学習計画案を生成します。
8. ユーザーが計画、学習目標の種類と達成条件、対応する教育課程項目、主要な根拠資料を確認・編集・承認します。
9. 最初のレッスンを開始します。

## 3. 通常の学習セッション

1. ダッシュボードからテーマを選びます。
2. 前回内容と、今回の`can_do`／`know`学習目標および達成判定方法を確認します。
3. AIの説明を読み、不明点を質問します。
4. 説明の根拠資料と教育課程上の位置を確認できます。
5. 具体例、別説明、ヒントを要求できます。
6. 前提理解が不足している場合は、前段階のレッスンへ戻る提案を受けます。
7. 演習に回答し、フィードバックを受けます。
8. 終了時に要約と次回内容を確認します。

## 4. 学習完了

1. 全モジュールを完了します。
2. 総合確認テストを受けます。
3. `can_do`／`know`別の目標達成度、判定証拠、苦手項目、推奨復習内容を確認します。
4. テーマを完了状態にします。

## 5. 観測可能な主要体験

- 計画上の現在位置が常に確認できます。
- 最終目標と各レッスンの目標が「できる」または「わかる」として表示され、その達成判定方法を確認できます。
- アプリ終了後も端末内の前回位置・要約・進捗から再開できます。
- 回答はストリーミング表示され、生成中に停止できます。
- 演習結果が概念別習熟度と次回推薦に反映されます。
- 教育内容の出典と、対応する教育課程項目を確認できます。
- 米国・ドイツでは、同じ国でも州または州相当教育管轄ごとに異なる教育課程・学習標準を選択できます。
- 苦手領域の前提へ戻った理由と、元の学習位置へ復帰する条件を確認できます。
